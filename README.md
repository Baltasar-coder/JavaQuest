# JavaQuest

Mazmorra en el navegador para aprender Java de principiante a experto: programas completos con `main`, Scanner, plantillas con Ctrl+Espacio y combates donde las órdenes del héroe se escriben en Java.

Sin dependencias: HTML, CSS y JavaScript puros, con un intérprete de Java propio.

## Jugar en local

```
node serve.js
```

Abre http://localhost:8080

## Tests

```
node tests/levels.test.js
```

Para activar las cuentas (Google/email) mira `LEEME-CUENTAS.md`.
